## Deviations worth review

- `with_settings_snapshot` is async and holds the write lock across the closure (upstream semantics).
- Rollback-on-commit test makes the settings directory read-only. It needs a non-root user; root ignores directory permissions.
- The watch now re-resolves the settings link on every debounced change and rewatches the destination.
- `redact_server_settings_for_client` lives in `runtime/server_settings.rs`. `ws.ts` callers belong to the WS task.
