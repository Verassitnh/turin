### PM decisions (locked in)

1. **Imported theme colors:** `theme_palettes::ThemeColors` and `ThemeDefinition` use
   `gpui_kit::SharedString` for color strings (and theme id/label). Built-ins use
   `SharedString::new_static`; imported themes can hold owned values. `get_theme_definition`
   clones a built-in match (custom/environment lookup still to port).
2. **`scopedSettings` patches:** use `serde_json::Value` objects with upstream merge
   semantics (typed accessors only where upstream has typed helpers). Not implemented yet.
3. **Open VSX HTTP:** `OpenVsxClient` trait in `crates/app/src/theme/open_vsx.rs`, reqwest
   impl + fake for tests; fixtures under `crates/app/tests/fixtures/open_vsx/`. Not
   implemented yet.

## What the UI agent (S1 / T20d) should call

Logic lives in `crates/app/src/settings_logic/` and `crates/app/src/theme/`. Do not edit
the settings screens from R3.

### Settings scope (Settings → every panel that scopes by project/checkout/machine)

- `validate_settings_scope_search(project, machine, checkout)` — URL params to
  `SettingsScopeSearch`. Blank values are dropped.
- `resolve_settings_scope(&search, &groups, &environments)` — returns
  `ResolvedSettingsScope<P>`. Its `kind` says `All`, `Environment`, `Project`,
  `Checkout` or `Unavailable`. Read `label`, `members`, `environment_ids` from it.
  `Unavailable` must block writes; it never widens to all environments.
- `SettingsScopeEnvironment { environment_id, label }` — the environment list input.

### Theme inspector (Settings → Appearance inspector)

- `inspect_theme_role_from_utilities(candidates)` — nearest-ancestor utility-class
  role. Pass each candidate's class list, nearest first.
- `theme_role_from_utility_class(class, kind)` and `theme_role_from_utilities(classes)`.
- `ProbedPaintRoles::record(role, changed_kinds)` and `first_role()` — collect probe
  results. Feed `changed_theme_paint_kinds(before, after)` from the probe.
- `theme_token_probe_color(current)` — the sentinel to write per token.
- `spotlight_rect(bounds, element_radius, viewport)`, `spotlight_placement(&rect)`,
  `spotlight_key(&rect)` — spotlight geometry and dedupe.

### Theme library (`crates/app/src/theme/`)

- **Resolution (ported):** `theme_palette::get_theme_definition`,
  `resolve_theme_appearance`, `get_standard_theme_colors`, `get_theme_colors_for_mode`,
  `get_theme_modes`, `theme_allows_sidebar_artwork`, `canonical_theme_preference`.
- **Palettes (ported):** `theme_palettes::BUILT_IN_THEMES`, `THEME_COLOR_ROLES`,
  `ThemeColors` / `ThemeDefinition` with `SharedString` fields. Role names are snake_case
  (e.g. `surface_raised`, not `surfaceRaised`).
- **Coming with custom-theme port:** `parse_theme_file`, `create_vivid_theme_colors`,
  `theme_id_from_name`, `is_reserved_theme_id`, `theme_color_to_hex`,
  `to_canonical_theme_color`, custom theme install/update/remove (in-memory + persistence
  wiring TBD for Turin).
