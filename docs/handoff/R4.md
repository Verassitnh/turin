## Gotchas

- Queue tests use `#[tokio::test(flavor = "current_thread")]`. A multi-thread
  runtime lets reconnect microtasks run before `release`.
- `await_attachment_uploads` takes `Vec<String>` by value. A borrowed slice
  of a temporary does not live across `.await`.
- Access revoked "while minting" must `flush()` after `start` and before
  `deny_all`. Upstream runs until the mint await on the same turn.
- Draft `set_file_upload` / `mark_file_upload_missing` / reattach replacement
  are on the `ComposerDraftUploads` trait. `composer/draft_store.rs` does not
  implement them yet.
- Uploaded ids stay plain strings. `ChatAttachmentId` rejects dots, and the
  upstream fixtures use ids like `pending-environment-1-image-1.png`.
- Clippy `-D warnings`: collapse `if let` chains, and alias
  `Arc<dyn Fn() + Send + Sync>` in test structs (`type_complexity`).
- Context-record ids fold with FNV-1a over UTF-16 units. The review range
  pattern is parsed by hand (`regex` has no backreferences). Clamp lengths
  are UTF-16, not bytes. The 25th test covers the reference helpers the
  upstream test file does not call.
- `prompt_stash_store` is the persisted v2 queue. Do not fold it into
  `draft_store::PromptStashEntry` (that one holds in-memory bytes). Tests
  use memory storage with `durable = false`. A fractional
  `pendingImageCount` fails the payload instead of truncating.
- Code-block highlighting tokenizes a refresh batch on a worker thread.
  The ProseMirror plugin is not ported. Offsets are UTF-16.
- The presentation registry lives under `components` with
  `#![allow(dead_code)]` because no view calls it yet. `components` itself
  is not allowed, unlike `composer`.
