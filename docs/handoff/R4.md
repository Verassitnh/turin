## Gotchas

- Queue tests use `#[tokio::test(flavor = "current_thread")]`. A multi-thread
  runtime lets reconnect microtasks run before `release`.
- `await_attachment_uploads` takes `Vec<String>` by value. A borrowed slice
  of a temporary does not live across `.await`.
- Access revoked "while minting" must `flush()` after `start` and before
  `deny_all`. Upstream runs until the mint await on the same turn.
- Draft `set_file_upload` / `mark_file_upload_missing` / reattach replacement
  are on the `ComposerDraftUploads` trait. `composer/draft_store.rs` does not
  implement them yet.
- Uploaded ids stay plain strings. `ChatAttachmentId` rejects dots, and the
  upstream fixtures use ids like `pending-environment-1-image-1.png`.
- Clippy `-D warnings`: collapse `if let` chains, and alias
  `Arc<dyn Fn() + Send + Sync>` in test structs (`type_complexity`).
