## Space shortcut

Parsed shortcuts hold their key as `keybindings::ShortcutKey(String)`, which accepts any text, so
`mod+space` parses to `" "` and matches a space press, as upstream does in memory. Resolved rules use the
module's `ResolvedKeybindingRule` and `ParsedShortcut`, not the contracts types, because contracts'
`KeybindingValue` trims and needs 1..=64 chars. Contracts are unchanged. N1's runtime copy
(`crates/runtime/src/shared_keybindings.rs`) can point at this module (DEDUP).
