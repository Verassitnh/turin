## Ported in the QC round

- Read cache race (QC medium). `load_or_lookup` keeps a loaded entry in memory only when its
  revision matches the request. `refresh` re-checks its post-invalidate read and takes a fresh lookup
  when the store holds a stale entry. Invalidate removes from the store, then memory. Regression
  tests: `a_read_that_loaded_the_store_before_an_invalidation_is_not_kept_under_the_new_revision`
  and `a_stale_entry_written_back_during_an_invalidation_is_not_served`. Both fail on the old logic
  and pass on the fix, and they are deterministic (a `PausingStore` stops one remove).
- The earlier "known issue" note was wrong: the failure reproduced on a quiet machine, and it is
  this race. Removed.
- 5725 update-branch refusal: `part_u.rs`, two cases. The host-side refusal (`updateMethods` on the
  host) and the viewer-side refusal (`updateMethods` on the viewer's permissions, which
  `actions.rs` checks). The `update_methods` field exists; the earlier note claiming it was missing
  was wrong.
- 1104, 1191, 3276 (GitHub halves): `part_v.rs`. An unusable host is reported over a merely failing
  one; a host filter never reads the other host; a reader's search reaches the host.
- 3732 (list and listStats retry after a canceled lookup): `part_w.rs`. See the deviation in
  PORTING.md: the Rust coalescer holds weak references, so the case pins the outcome, not the
  interleaving.
- Head-check timeout: `git rev-parse --verify HEAD` runs under the 30s default, not no deadline
  (`repository_service.rs`, `the_head_check_runs_under_the_drivers_default_deadline_...`).
- Media fetch timeouts: connect 10s and per-hop header wait 30s, with the body untimed. A hop that
  times out is a broken hop, so the answer is a 502 (`a_hop_that_never_sends_headers_...`).
- Review guide raw stops: provider-core's `ReviewGuideGenerationResult` holds the model's raw stops
  (types moved from text-generation). The normalizer takes them and returns contract stops. The
  service's test `briefs_the_change_...` covers the path end to end.
