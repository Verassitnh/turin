# T09 handoff: provider-codex

Branch `task/T09-codex-adapter`. Gate: `scripts/check.sh -p turin-provider-codex`.

## Done (group 1: items, nodes, deltas, usage)

- `crates/provider-codex/src/items.rs`: artifact builders for `agentMessage`,
  `reasoning` parts, `commandExecution`, `webSearch`, `fileChange`, proposed
  `plan`, and `turn/plan/updated` todo lists. Ordinals follow upstream
  `resolveItemPosition` (`providerTurnOrdinal * 100 + position + 1`).
- `crates/provider-codex/src/projection.rs`: notification dispatch and the
  text-delta coalescer. Assistant and reasoning share a 50 ms flush group, plan
  text uses 400 ms. Turn end flushes buffers and marks still-running commands
  interrupted or failed. `thread/tokenUsage/updated` drives provider turn usage;
  `turn/completed` carries `turnTokenUsage`.
- `crates/provider-codex/src/orchestration_adapter.rs`: a pump task projects
  frames as they arrive, so interrupt sees running commands. Frames for a turn
  not yet registered by `turn/start` are parked in order (cap 4096) and drained
  on registration. Interrupt sends `thread/backgroundTerminals/terminate` for
  each running command with a process id, through the raw client.
- Replay tests: `todo_list`, `web_search`, `proposed_plan`, `turn_interrupt_mid_tool`
  added to `replay_tests.rs`. 23 tests pass (9 unit, 14 replay), stable over 8 runs.

## Notes for the next agent

- Pump and parking: `ingest` parks any frame whose turn is unregistered, or
  behind a parked frame for the same turn. A turn that never registers is
  dropped at the cap. Check this before adding child-turn registration.
- `project_event` removes the turn from `state.turns` while it works and reinserts
  it. A `turn/completed` does not reinsert. Keep that invariant when adding
  per-turn state.
- Replay timing: the test harness runs frames without delay, so text flushes
  rarely fire. Assertions use completed assistant items only (`assistant_texts`).
- Driver: `thread/backgroundTerminals/*` is not in the pinned typed surface.
  Use `client.raw.request`.
- PORTING rows updated: fixture coverage, item mapping, plus two new
  deviation rows (projection timing, background terminals).
