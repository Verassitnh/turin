## Notes for whoever picks this up

- Registry state is session-scoped (`ClaudeActor.subagents`) and its scope is set on each `start()`. A background subagent reports against the last turn's root node.
- `stream_event` frames are only read for thinking. Text blocks still come from the completed assistant message.
- `ToolCall.output` is the native value (structured if present). `ToolCall.output_fallback` is the content behind a structured value. `command_output_text` reads the fallback when both streams are empty.
- The Claude model regex (`claude_writes_updates_as_thinking`) uses the `regex` workspace crate. Lookahead is not supported there, so the minor version uses `\b`.
- Build contention: cargo runs take 10-25 s for this crate when the cache is warm.
