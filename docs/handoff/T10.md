## Notes for whoever picks this up

- Subagent state lives in `claude_subagents.rs` (`Task`: record, ids, child, confirmed outcome). Lifecycle methods return ordered `ProviderAdapterV2Event` lists. The actor only emits them.
- `TurnScope.run_id` is `Option`. `None` means a child-thread item (upstream `runId: null`).
- `SubagentScope` carries the parent `app_thread` and `model_selection`, which child threads copy.
- The roster is session-scoped. `emit_thread` uses the active turn's thread when one runs, else `last_thread`.
- Goal state is session-scoped, seeded once from `provider_thread.goal`.
- Registry state is session-scoped (`ClaudeActor.subagents`). A background subagent reports against the root node of the turn that launched it.
- `ToolCall.output` is the native value (structured if present). `ToolCall.output_fallback` is the content behind a structured value.
- The Claude model regex uses the `regex` workspace crate. Lookahead is unsupported there, so the minor version uses `\b`.
- Build contention: cargo runs take 10-25 s for this crate when the cache is warm.
