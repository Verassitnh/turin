## Open deviations (also in PORTING.md)
- **Text generation** stays with N3. `UnavailableClaudeTextGeneration` returns not-implemented.
- **Adapter catalog is fixed at create.** A fetched manifest reaches the snapshot on the next check, not the adapter's model table.
- **Plugin skill directories** are not scanned.
- **Version advisory** reports the update command, but running it is not wired.
- **Reset coordinator** is per driver, not process-wide.
- **Assumptions to confirm.** Attachments dir is `$TURIN_HOME/userdata/attachments`. Runtime instructions use harness name `Turin`. `McpProviderSessions` and `ProviderContinuationRequests` are not passed to the driver.
- **Skill YAML** uses `yaml-rust2`, not the `yaml` npm package. Edge cases in malformed frontmatter may differ. The repair pass matches upstream.
- **Skill sort** is case-insensitive, approximating `localeCompare`.
