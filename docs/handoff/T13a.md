## Design decisions

- **Writer seam**: `store/apply.rs::apply_event(&Connection,&OrchestrationV2DomainEvent)` runs inside the caller's `Db::write` closure; the sink appends the
  event and projects it in one transaction and publishes only after commit. `ProjectionStore::apply` is a convenience wrapper for tests.
- **Reads** use the reader connection via `Db::read`; multi-statement reads run in one `unchecked_transaction` (`read_tx`) so they agree.
  Errors: raw causes become `ProjectionStoreError::Read{thread_id}`; `ThreadNotFound` passes through (`keep_or_read`).
- **Raw SQL is copied verbatim** from upstream (window query, retained-node CTE, shell query, limit-recovery). Plan tests (`window_tests.rs`) assert the same
  EXPLAIN QUERY PLAN details; they rely on migration 060 indexes. The SQL is exposed as `pub(crate) const` for that.
- `Option<Option<T>>` = TS `optional(NullOr)` (see contracts `double_option`); shell rows set the outer `Some`.
- Merge semantics kept in SQL: `run.created/updated` keeps `delegatedCompletion`/`restartCancelledBackgroundWork`; `subagent.updated` keeps
  `completionDelivery`; `provider-turn.updated` keeps `tokenUsage`; thread-activity events patch `updatedAt` in place via `json_set` (no read-back).
  `thread.visited/marked-unread/...` do not bump activity; run/node/turn-item/etc. do (`bumps_thread_activity`).
- `thread.pull-request-link-updated` loads the stored thread, patches one link (`apply_thread_pull_request_link_update`), upserts, then bumps activity.
- Item "same reference" checks use `Cow::Borrowed` / `std::ptr::eq` instead of JS identity.

## Gotchas

- Fixtures in `test_support.rs` are JSON-shaped like upstream literals. A new fixture often fails on a missing required field (`driver` on `nativeItemRef`,
  `capabilities` on sessions, `startedAt` etc.) -- the error is serde "missing field".
- `turin_contracts::ProviderInstanceId` is not re-exported at crate root: use `turin_contracts::provider_instance::ProviderInstanceId`.
- `UtcDateTime` is `Copy`, ms-truncated, sorts like the wire string. Use `.to_string()` for SQL timestamp columns.
- `SqlBuilder::bind` takes owned values (`String`), not `&str`.
- Windows/paging tests use a file DB (`file_store()`) so reads hit the reader connection; in-memory `Db` has no separate reader.
- `shell.rs` holds stand-in `thread:shell` id for cross-thread reads' error label.
- `thread_live_event_coalescer` takes any `OrchestrationV2ThreadStreamItem` (including `Synchronized`, which flushes immediately).
- Cargo: `unicode-segmentation = "1"` added directly to the crate (already in Cargo.lock) for monogram grapheme counting.
