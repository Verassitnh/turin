## Gotchas
- `ProviderSessionRuntime::close` is an additive default (T08 to reconcile). Release calls it before drop.
- Self-releasing tasks (idle timer, event pump) detach their own handle before releasing, or the release is
  aborted mid-write. Keep the pattern in new background tasks.
- Tests use `#[tokio::test(start_paused = true)]` (dev-dep `tokio` has `test-util`).
- Crate `tokio-util` needs feature `rt` for `AbortOnDropHandle` (enabled in crate Cargo.toml).
- `rustfmt --edition 2024` on new files only; `cargo fmt --all` touches others' files.
- Fake-runtime test fixtures use JSON via `serde_json::from_value`; event variant fields are snake_case
  (the enum has no `rename_all` on fields); top-level keys are camelCase only for contract payloads.
