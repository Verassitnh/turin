## Gotchas
- `ProviderSessionRuntime` has no `close()`. Release drops the runtime Arc; adapters must stop
  their process on last drop (see needs file).
- Self-releasing tasks (idle timer, event pump) detach their own handle before releasing, or the
  release is aborted mid-write. Keep that pattern in new background tasks.
- Tests use `#[tokio::test(start_paused = true)]` (dev-dep `tokio` has `test-util`).
- Crate `tokio-util` needs feature `rt` for `AbortOnDropHandle` (enabled in crate Cargo.toml).
