## Gotchas

- `TurinCheckpointGit` runs real git. The `checkpoint_git` round-trip test failed once in a full parallel run with a 30 s `resolveCheckpointCommit` timeout. It passed on two reruns and alone (1.4 s). Watch for flakes. If it recurs, check the VCS process semaphore for a leaked permit.
- `UtcDateTime` and `PositiveInt` are `Copy`. Clippy rejects `.clone()` on them.
- `\0` followed by a digit in a Rust string literal is an octal escape error. Use `concat!`.
- Checkpoint numstat is NUL-delimited (`additions\tdeletions\tpath\0`).
- Ordinal 0 captures diff a ref against itself. Git returns an empty diff, and upstream relies on that.
