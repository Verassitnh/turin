## Gotchas

- `TurinCheckpointGit` runs real git. The round-trip test failed once in a full parallel run with a 30 s `resolveCheckpointCommit` timeout, and passed on two reruns and alone (1.4 s). If it recurs, check the VCS process semaphore for a leaked permit.
- `UtcDateTime` and `PositiveInt` are `Copy`. Clippy rejects `.clone()` on them, and on `Option<Option<CopyEnum>>`.
- `\0` followed by a digit in a Rust string literal is an octal escape error. Use `concat!`.
- Checkpoint numstat is NUL-delimited (`additions\tdeletions\tpath\0`).
- Ordinal 0 capture diffs a ref against itself. Git returns an empty diff, and upstream relies on that.
- `ThreadManagementService` has no inherent `dispatch`. Call it on the core through `Deref`.
