# T19 handoff: GitHub pull request views

Branch `task/T19-pull-requests` (base T16 thread view + T14 client state merged). Everything lives in
`crates/app/src/pull_request/` plus small shared pieces (below). Nothing calls a real GitHub service:
views render from `view_model.rs` and `mock_source.rs`; T22 replaces the mock with the T07 source.

## Run it

```
cargo build -p turin
scripts/shot.sh out.png TURIN_APPEARANCE=dark TURIN_PULL_REQUESTS_DEMO=list
```

`TURIN_PULL_REQUESTS_DEMO` = `list[:all|filters|authored|empty|error|loading]`,
`detail[:summary|timeline|code|guide[:<number>]]` (463/468 merged, 465 closed, 479 conflicting, 491 draft),
`thread[:link[:<text>]]`. Screenshots are in `docs/screenshots/T19/`.

## Layout

| Concern | Files |
|---|---|
| Pure logic + tests (1:1 with upstream `*.logic.ts` and tests) | `pull_request_*_logic.rs`, `pull_request_{list_lines,list_preferences,presentation,review_store,stack_snapshot}.rs`, `pull_requests_route_search.rs`, `link_pull_request_dialog_logic.rs`; big test files in `pull_request_{list,detail}_logic_tests/` |

| List page | `list_page.rs`, `list_row.rs`, `list_filters.rs`, `list_states.rs`, `dropdown.rs` |
| Detail panel + tabs | `panel_host.rs`, `detail_panel.rs`, `detail_layout.rs`, `summary_tab.rs`, `timeline_tab.rs`, `code_tab.rs`, `guide_tab.rs`, `guide_view.rs`, `checks_popover.rs`, `stack_popover.rs`, `pickers.rs`, comment/review forms |
| Thread ↔ PR | `thread_panel.rs`, `thread_links.rs`, `link_dialog.rs`, `link_preview.rs` |
