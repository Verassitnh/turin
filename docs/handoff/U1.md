## Seams for T22 / T14
- `PaletteBackend` (`palette_source.rs`): snapshot (sidebar snapshot + context flags), message search, settings search, folder browse, add/create project, restart session. Palette emits `CommandPaletteEvent` for navigation; the shell currently maps most of them to "not available yet" toasts.
- `GitActionsBackend` (`git_actions_control/backend.rs`) and `BranchBackend` (`branch_toolbar/backend.rs`): status, action state, stacked action, pull, init, publish, refs, switch/create ref, thread metadata. `GitActionsControl` emits `GitActionsControlEvent`, `BranchToolbar` emits `BranchToolbarEvent` (draft context / env mode / branch override changes) — the composer (T17) owns the draft store that should consume them; `ChatGitHost` keeps that state locally until then.
- Settings search (`search_settings`), keybinding labels (defaults only, `shortcut_labels.rs`), custom/environment themes and light/dark halves belong to T20.
