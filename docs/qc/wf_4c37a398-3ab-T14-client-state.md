### [low] Commit file paths are silently filtered, so an invalid path can commit a partial file set
- `crates/app/src/state/helpers/vcs_action.rs:735` · dimension: logic-fidelity · upheld 2/2
- Evidence: Upstream vcsAction.ts passes filePaths: [...input.filePaths] verbatim when length > 0. The contract (upstream git.ts:133) makes each entry a non-empty string and the array min length 1, so an empty path fails the RPC. build_git_run_stacked_action_input uses filter_map(|path| GitFilePath::new(path.clone()).ok()), which drops empty paths without error. Input ["a", ""] therefore runs the stacked action on "a" only, and input [""] sends Some(vec![]), which the contract rejects. Upstream returns an error in both cases.
- Fix: Return an error when any path fails GitFilePath::new (or pass the Vec through unchanged) instead of dropping entries with filter_map.
