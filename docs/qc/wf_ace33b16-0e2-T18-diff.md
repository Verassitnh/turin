- Evidence: Rust: `fn gutter_width(...) { ctx.metrics.ch * (2. + ctx.digits as f32 + 1.) + px(3.) }` with `digits` = digit count of total lines (line 1241). Upstream @pierre/diffs style.js: `[data-line-number-content]{min-width:var(--diffs-min-number-column-width,var(--diffs-min-number-column-width-default,3ch))}` (no override defined anywhere in apps/web/src), and `[data-column-number]{box-sizing:content-box;padding-left:2ch}` plus the shared `[data-line],[data-column-number],[data-no-newline]{padding-inline:1ch}` and a 2px border-right.
